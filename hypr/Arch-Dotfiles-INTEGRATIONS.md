# Arch Dotfiles — связи компонентов

Версия 1 от 21.09.2026. Этот файл — сохранённая основа для следующих этапов. При создании Waybar, Kitty, Fuzzel и SwayNC использовать эти пути и имена; при их изменении обновлять обе стороны связи.

## Предпочтения и принятые решения

Из предыдущего обсуждения: Arch Linux + Hyprland; настольный ПК с RTX 5060; тёмная тема с фиолетовыми акцентами; компактный полупрозрачный Kitty; аккуратный prompt; верхняя панель с workspaces, CPU/RAM/GPU, температурой, сетью и временем; обязательный текущий язык EN/RU; launcher Fuzzel; уведомления SwayNC; справка по хоткеям; работа с кодом, заметками и файлами. Для оболочки планируются zsh/Starship.

Решения этой версии: Lua API Hyprland 0.56.2; `dwindle`; Super как основной модификатор; переключение EN/RU через Alt+Shift и Super+Space; фокус по клику; автоматические параметры неизвестных мониторов; пять постоянных числовых рабочих столов. Firefox, Thunar, Code и Obsidian — стартовые заменяемые команды, их выбор пользователем ранее не подтверждён.

## Пути и точки входа

Ниже `~/.config` означает `${XDG_CONFIG_HOME:-$HOME/.config}`. При нестандартном XDG_CONFIG_HOME всё дерево должно находиться там.

| Компонент | Будущий / текущий файл | Связь с Hyprland и состояние |
|---|---|---|
| Hyprland | `~/.config/hypr/hyprland.lua` | Создан, подключает `conf/*.lua` явно |
| Общие команды и цвета | `~/.config/hypr/conf/settings.lua` | Создан; исходные значения для следующих конфигов |
| Waybar | `~/.config/waybar/config.jsonc`, `style.css` | Ещё не созданы; автозапуск только при наличии обоих файлов |
| Kitty | `~/.config/kitty/kitty.conf` | Ещё не создан; запускается штатно по Super+Enter |
| Fuzzel | `~/.config/fuzzel/fuzzel.ini` | Ещё не создан; читается Fuzzel автоматически, Super+D |
| SwayNC | `~/.config/swaync/config.json`, `style.css` | Ещё не созданы; автозапуск при наличии обоих, Super+A → `swaync-client -t` |
| Hyprpaper | `~/.config/hypr/hyprpaper.conf` | Ещё не создан; подключится автозапуском по наличию файла |
| Hyprlock | `~/.config/hypr/hyprlock.conf` | Ещё не создан; Super+L проверяет готовность перед запуском |
| Hypridle | `~/.config/hypr/hypridle.conf` | Ещё не создан; автозапуск требует также Hyprlock и его конфиг |
| Хоткеи | `~/.config/hypr/conf/bindings.lua` | Создан; единый источник привязок и описаний |
| Справка | `~/.config/hypr/scripts/show-keybinds.py` | Создан; Super+K → Fuzzel dmenu, читает `hyprctl -j binds` |
| Редактирование хоткеев | Kitty → Nano → `bindings.lua` | Super+Ctrl+K; затем сохранение/`hyprctl reload` |
| zsh / Starship | `~/.zshrc`, `~/.config/starship.toml` | Ещё не созданы; Kitty будет запускать shell пользователя |

Не добавлять `require()` на несуществующие конфиги других приложений: их читает соответствующая программа, не Hyprland. Прямой автозапуск принадлежит `scripts/autostart.sh`; не включать параллельные экземпляры тех же демонов через другие механизмы. Агент Polkit запускается через его пользовательскую службу.

| Роль | Значение |
|---|---|
| Основной фон | `#11111b` |
| Поверхность панели/окон | `#1e1e2e` |
| Дополнительная поверхность | `#313244` |
| Основной текст | `#cdd6f4` |
| Вторичный текст | `#a6adc8` |
| Основной акцент | `#cba6f7` |
| Второй цвет градиента | `#9d7cd8` |
| Неактивная рамка | `#45475a` |
| Рамка / скругление | 2 px / 10 px |
| Отступы внутри / снаружи | 5 px / 10 px |
| Целевая прозрачность фона Kitty | `background_opacity 0.92`, реализовать в `kitty.conf` |

`settings.lua` не импортируется автоматически в CSS/INI: при создании остальных конфигов перенести эти значения явно. Автоматической генерации общей темы пока нет.

У Hyprland общая opacity окон равна 1.0. Не добавлять параллельное правило `opacity` для Kitty: иначе полупрозрачными станут и текст, и фон. Начальная версия Kitty использует стандартный вид до следующего этапа.

## Waybar

- Положение сверху; резервирование места через exclusive zone самой панели. Дополнительного reserved-area в Hyprland нет.
- `hyprland/workspaces`: сохранять числовые ID. Роли/подписи 1 = terminal, 2 = code, 3 = web, 4 = notes, 5 = files. Столы 6–10 — дополнительные. Это подписи, не автоматическая сортировка окон.
- `hyprland/language`: показывать `EN`/`RU` для текущей клавиатуры. Конфиг Hyprland содержит `kb_layout = "us,ru"`; при необходимости `keyboard-name` взять из `hyprctl devices`, не придумывать.
- Метрики: CPU, RAM, GPU, температура, сеть, часы/дата; дополнительно звук и tray. GPU — будущий `custom/gpu`, данные NVIDIA через `nvidia-smi`; проверить фактические поля и частоту опроса на ПК.
- Кнопка справки может вызывать `python3 "$HOME/.config/hypr/scripts/show-keybinds.py"`; при нестандартном XDG_CONFIG_HOME использовать его.
- Namespace ожидается `waybar`. Blur уже подготовлен в `rules.lua`.

## Kitty, Fuzzel и окно хоткеев

Обычный Kitty остаётся плиточным. Команда `kitty --class arch-float-terminal` получает плавающее окно 62% ширины и 64% высоты монитора по центру. Не переименовывать этот class без изменения `rules.lua`. Смена терминала в `settings.lua` требует также замены аргумента `--class` в соответствующем хоткее, если новый терминал его не поддерживает.

У справки хоткеев один источник данных: реальные `description` из Hyprland IPC. Fuzzel запускается как dmenu, не исполняет строки. Будущий отдельный виджет может заменить `show-keybinds.py`, сохранив Super+K и тот же источник данных. Графическое управление привязками пока не реализовано.

Fuzzel ожидается с namespace `launcher`; подтвердить через `hyprctl layers`. Справка и launcher используют общий `fuzzel.ini`, поэтому оформление делается один раз. Команда справки пока прямо вызывает `fuzzel`: замена `apps.launcher` не меняет этот помощник автоматически.

## SwayNC, обои, блокировка

SwayNC namespaces: `swaync-control-center`, `swaync-notification-window`; сверить на установленной версии. Super+A вызывает проверенный работающий демон через `swaync-client -t`. Будущая кнопка Waybar должна использовать ту же команду либо `session-action.sh notifications`.

Обои позднее хранить в `~/.local/share/backgrounds/arch-dotfiles/`; при нестандартном XDG_DATA_HOME использовать его. В текущей версии нет ссылки на несуществующий PNG; фон однотонный.

Hyprlock вызывается с явным путём `-c .../hyprlock.conf`. Будущий `hypridle.conf` должен использовать ту же блокировку, корректно дожидаться захвата session lock до сна и задавать таймауты. До готовности этих файлов нет автоблокировки/блокировки перед сном. Не объявлять это реализованным только из-за присутствия Super+L.

## Границы текущего этапа

Установщик после archinstall, dotfiles-репозиторий, перенос пользовательских данных, экран входа, UWSM, GPU-драйвер, конфиги Waybar/Kitty/Fuzzel/SwayNC/zsh/Starship, Hyprpaper/Hyprlock/Hypridle — следующие этапы. Данный комплект их не устанавливает и не меняет системные настройки.

Проверка здесь ограничена синтаксисом и соответствием API/связей. Реальные мониторные режимы, EN/RU на физической клавиатуре, драйвер NVIDIA, звук и порталы проверяются в целевой графической сессии.
