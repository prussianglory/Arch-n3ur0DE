# Arch Dotfiles — Hyprland

Версия комплекта: 1. Дата: 21 сентября 2026 года. Целевая версия: **Hyprland 0.56.2**, обычная сессия Hyprland на Arch Linux. Это первый этап окружения; настройки остальных приложений будут добавлены отдельно.

Комплект сохраняет выбранное направление: тёмное оформление с фиолетовыми акцентами, рабочее окружение для учёбы и программирования, плиточные окна и отдельный компактный терминал, EN/RU, будущая верхняя панель с системными метриками и справка по сочетаниям клавиш.

## Почему файлы Lua

Начиная с Hyprland 0.55 основной формат конфигурации — Lua. Точка входа — `hyprland.lua`. Старые инструкции с `hyprland.conf`, `source =` и `windowrulev2` нельзя механически смешивать с этим комплектом. На дату подготовки пакет Arch — 0.56.2-3. См. [формат конфигурации](https://wiki.hypr.land/Configuring/Start/) и [пакет Arch](https://archlinux.org/packages/extra/x86_64/hyprland/).

Проверь установленную версию:

```bash
Hyprland --version
```

Комплект рассчитан на API 0.56.2. Совместимость с будущими версиями не предполагается автоматически. Если установлен Hyprland 0.54 или старее, сначала нужна актуализация системы либо отдельная версия конфигов для старого синтаксиса.

## Что находится в архиве

Верхняя папка — `Arch-Dotfiles`. В ней лежат этот файл, `Arch-Dotfiles-INTEGRATIONS.md` и папка `hypr`. Вся папка `hypr` копируется в каталог конфигурации пользователя.

| Файл внутри `hypr/` | Что редактировать здесь |
|---|---|
| `hyprland.lua` | Порядок подключения модулей |
| `conf/settings.lua` | Приложения, Super, общая палитра |
| `conf/environment.lua` | Переменные окружения и режим курсора NVIDIA |
| `conf/monitors.lua` | Разрешение, герцовка, масштаб и расположение экранов |
| `conf/input.lua` | EN/RU, переключение раскладки, мышь и повтор клавиш |
| `conf/appearance.lua` | Отступы, рамки, скругление, blur, тени |
| `conf/animations.lua` | Длительность и стиль анимаций |
| `conf/workspaces.lua` | Постоянные столы 1–5 и scratchpad |
| `conf/rules.lua` | Правила окон и слоёв приложений |
| `conf/bindings.lua` | Сочетания клавиш и подписи для справки |
| `conf/autostart.lua` | Обработчик старта сессии |
| `conf/local.lua` | Небольшие личные переопределения |
| `scripts/autostart.sh` | Проверка готовности и запуск фоновых компонентов |
| `scripts/session-action.sh` | Блокировка, уведомления, снимки экрана |
| `scripts/show-keybinds.py` | Поисковая справка из действующих привязок Hyprland |

В каждом модуле есть русские комментарии с назначением параметров и примерами изменений.

## Зависимости

| Назначение | Пакеты / команды |
|---|---|
| Базовый запуск и справка | `hyprland`, `kitty`, `fuzzel`, `python`, `nano` |
| Служебные проверки | `bash`, `util-linux` (`flock`), `procps-ng` (`pgrep`), `systemd`, `dbus` |
| Звук и медиаклавиши | Работающая связка `pipewire`, `pipewire-pulse`, `wireplumber`; дополнительно `playerctl` |
| Снимки в буфер | `grim`, `slurp`, `wl-clipboard` |
| Графические запросы прав | `hyprpolkitagent` |
| Порталы и демонстрация экрана | `xdg-desktop-portal-hyprland`, `xdg-desktop-portal-gtk` |
| Примеры приложений в хоткеях | `firefox`, `thunar`, `code`, `obsidian`; можно заменить команды |
| Следующий этап оформления | `waybar`, `swaync`, `hyprpaper`, `hyprlock`, `hypridle` |

Например, для основы и скриншотов на уже установленном Arch:

```bash
sudo pacman -Syu --needed hyprland kitty fuzzel python nano \
    util-linux procps-ng grim slurp wl-clipboard
```

Это не полный установщик рабочего стола: сеть, звук, порталы и видеодрайвер должны быть настроены в самой системе. Firefox, Thunar, Code и Obsidian выбраны как **заменяемые значения по умолчанию**, а не как уже согласованный выбор. Неустановленное приложение по соответствующему хоткею не откроется; меняй `apps` в `conf/settings.lua`.

## Установка

Распакуй архив. Открой терминал **внутри извлечённой папки `Arch-Dotfiles`**, где видна папка `hypr`.

Выполни от обычного пользователя, без `sudo`. Лучше делать это из TTY либо после выхода из текущей графической сессии, чтобы автоперечитывание не застало копирование файлов в середине.

```bash
config_dir="${XDG_CONFIG_HOME:-$HOME/.config}"
mkdir -p -- "$config_dir"

# Существующую конфигурацию, в том числе символьную ссылку, сохраняем целиком.
if [ -e "$config_dir/hypr" ] || [ -L "$config_dir/hypr" ]; then
    backup_dir="$(mktemp -d "$config_dir/hypr-backup.XXXXXXXX")"
    mv -- "$config_dir/hypr" "$backup_dir/hypr"
    printf 'Предыдущая конфигурация: %s/hypr\n' "$backup_dir"
fi

cp -a -- ./hypr "$config_dir/hypr"
```

Скрипты вызываются явно через `bash` и `python3`, поэтому потеря executable bit при распаковке ZIP на Windows не мешает их работе. Файлы должны оставаться в UTF-8 с Unix-переносами LF.

После копирования войди в обычную сессию Hyprland своим способом. Комплект не меняет экран входа, shell и способ старта системы. Если ты выбрал сессию **UWSM**, прежде нужно согласовать её окружение и автозапуск: это не проверенный путь для данной версии комплекта. [Документация UWSM](https://wiki.hypr.land/Useful-Utilities/Systemd-start/).

При установке из уже работающего Hyprland:

```bash
hyprctl reload
hyprctl configerrors
```

Изменения окружения требуют нового входа. Автозапуск привязан к началу сессии и не повторяется на `reload`.

## Первые хоткеи

`Super` — клавиша Windows. Буквы ниже соответствуют позициям английской раскладки.

| Сочетание | Действие |
|---|---|
| Super+Enter | Обычный плиточный Kitty |
| Super+Ctrl+Enter | Компактный плавающий Kitty |
| Super+D | Поиск приложений Fuzzel |
| Super+E / B / C / N | Файлы / браузер / код / заметки |
| Super+Q | Закрыть активное окно |
| Super+V | Переключить плиточный и плавающий режим |
| Super+F / Super+Shift+F | Полный экран / развернуть в рабочей области |
| Super+стрелки | Перевести фокус |
| Super+Shift+стрелки | Переместить окно |
| Super+Ctrl+стрелки | Изменить размер окна |
| Super+1…9,0 | Перейти на стол 1…10 |
| Super+Shift+1…9,0 | Перенести окно на стол, оставаясь на текущем |
| Super+S / Super+Shift+S | Показать scratchpad / отправить в него окно |
| Alt+Shift либо Super+Space | Переключить EN/RU |
| Super+K | Поисковая справка по действующим хоткеям |
| Super+Ctrl+K | Редактировать `bindings.lua` в Nano |
| Super+Shift+R | Перечитать конфигурацию |
| Super+A | Центр уведомлений, после настройки SwayNC |
| Super+L | Блокировка, после настройки Hyprlock |
| Print / Shift+Print | Область / все мониторы в буфер обмена |
| Super+ЛКМ / ПКМ | Перетаскивать / менять размер окна |

В Nano: `Ctrl+O`, Enter — сохранить; `Ctrl+X` — выйти. Чтобы вернуть окно из scratchpad на обычный стол, сфокусируй его и нажми `Super+Shift+номер`.

Справка Super+K — пока простой Fuzzel-оверлей с поиском. Она читает `hyprctl -j binds`, поэтому подписи и привязки обновляются вместе с конфигом. Выбранная строка не запускает команду. Для изменения используется Super+Ctrl+K; полноценного графического редактора хоткеев пока нет.

## Что появится на следующем этапе

Панель и уведомления запускаются только при наличии соответствующих конфигов. До их создания **не будет верхней панели, её индикатора EN/RU и метрик CPU/RAM/GPU**. Переключение раскладки уже работает. Fuzzel и Kitty используют свои стандартные настройки, пока мы не подготовим оформление.

Фон Hyprland сейчас однотонный тёмный. Фоновое изображение добавит Hyprpaper. Прозрачность только фона терминала, шрифт, компактные отступы и prompt появятся в настройках Kitty и zsh/Starship.

**Автоблокировки и блокировки перед сном пока нет.** Hyprlock/Hypridle относятся к следующему этапу. Super+L прямо сообщает, если locker или конфиг отсутствуют; такое сообщение не означает, что экран заблокирован.

Когда появятся новые файлы, повторно выполни:

```bash
bash "${XDG_CONFIG_HOME:-$HOME/.config}/hypr/scripts/autostart.sh"
```

Этот скрипт запускает отсутствующие процессы, но не перезапускает уже работающие для применения их новых настроек. На данном этапе он рассчитан на одну графическую сессию текущего пользователя.

Точные пути и договорённости сохранены в **Arch-Dotfiles-INTEGRATIONS.md**.

## Как менять настройки

1. Открой нужный модуль по таблице выше.
2. Измени одно значение, сохраняя кавычки, запятые и фигурные скобки.
3. Выполни `hyprctl reload`, затем `hyprctl configerrors`.
4. Проверь результат; переменные окружения проверяй после нового входа.

Например, отступы — `gaps_in`/`gaps_out` в `appearance.lua`, скорость мыши — `sensitivity` в `input.lua`, монитор — `monitors.lua`, программа заметок — `apps.notes` в `settings.lua`.

`local.lua` загружается последним и подходит для переопределения обычных значений `hl.config`. Привязки и правила могут добавляться поверх старых, поэтому существующие хоткеи меняй непосредственно в `bindings.lua`.

## Проверка на твоём ПК

```bash
hyprctl version
hyprctl configerrors
hyprctl monitors all
hyprctl devices
hyprctl clients
hyprctl layers
python3 "${XDG_CONFIG_HOME:-$HOME/.config}/hypr/scripts/show-keybinds.py" --print
```

Лог автозапуска: `${XDG_STATE_HOME:-$HOME/.local/state}/arch-dotfiles/autostart.log`.

Если графическая сессия не стартует, из TTY перенеси новую папку `hypr` в другое место и верни сохранённую папку `hypr-backup.XXXXXXXX/hypr` под прежнее имя. Путь резервной копии выводит команда установки.

Для RTX 5060 важна предварительная настройка поддерживаемого драйвера и DRM KMS. Строка `__GLX_VENDOR_LIBRARY_NAME` этого не заменяет. Для серии RTX 50xx документация указывает открытые модули ядра NVIDIA; конкретный пакет зависит от выбранного ядра. [NVIDIA и Hyprland](https://wiki.hypr.land/Nvidia/).

При подготовке проверены синтаксис Lua/Bash/Python, ссылки между файлами и параметры по исходникам Hyprland 0.56.2. Графическая сессия Hyprland здесь не запускалась: реальную работу дисплеев, драйвера RTX 5060 и взаимодействие с приложениями нужно проверить на твоём ПК.
